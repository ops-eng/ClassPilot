Help — ClassPilot

Quick summary: ClassPilot helps you organize school life in one place: courses, lessons, assignments, tasks, exams, grades, documents, cards, and study logs.

Tip: Best first setup path: More → Courses → Add Course, then add lessons/work items and enable reminders for key deadlines.

Basics First: How to Use the App

  • Tap actions: tap cards or rows to open details; use the plus button in the top-right to create new items; use filter chips to refine lists.
  • Swipe actions: most list rows support quick Edit, Done/To Do, Pin/Unpin, or Delete actions.
  • Menus: ellipsis buttons open contextual actions such as Share, Duplicate, Edit, Delete.
  • Reordering: drag handles reorder items in reorder-enabled lists.
  • Status flow: use To Do → In Progress → Done for assignments and tasks.
  • Color coding: set consistent colors per subject for easier scanning and filtering.

Navigation and Paths

  • Primary tabs: Dashboard, Planner, Work, Cards, More.
  • More tab includes: Documents, Lessons, Courses, Grades, Teachers, Insights, Intelligence, Settings, Help.
  • iPad layout: on regular width, use the left sidebar for Planner, Academics, Resources.

Dashboard

Path: Dashboard tab.

  • Use dashboard cards for a quick summary of upcoming lessons, due work, and exams.
  • Use quick actions to jump to key workflows faster.

Planner

Path: Planner tab.

  • Day and week planning surfaces show schedule density, upcoming deadlines, and timeline events.
  • Use the planner to review workload by date and open related items quickly.
  • Timeline behavior is optimized for overlap handling so simultaneous events remain readable.

Work

Path: Work tab (Assignments, Tasks, Exams, Study, Lessons).

  • Assignments: add/edit title, due date, type, priority, reminders, course, teacher.
  • Tasks: lightweight tasks optimized for quick entry and completion.
  • Exams: add date/time, type, weight, reminders, course/teacher.
  • Study: log sessions, track notes, and keep focus history.
  • Tip: use swipe actions for speed and edit sheets for full metadata updates.

Courses

Path: More → Courses.

  • Create courses with code, color, credits, location, teachers, and notes.
  • Use filter chips: Group, Sort, Teacher, Day, Credits, Color.
  • Course Preview shows teacher, next lesson, assignments count, upcoming exams, attendance, credits.
  • View Details shows attendance, lessons, assignments, tasks, tests, study sessions, documents.

Lessons

Path: More → Lessons.

  • Track scheduled lesson items with location, teacher, notes, reminders, and course linkage.
  • Use edit, duplicate, and delete actions to maintain your timetable quickly.

Documents

Path: More → Documents.

  • Store links and files tied to courses, assignments, and exams.
  • Supported flow: add web docs, import files, preview and open attachments in-app.

Grades

Path: More → Grades.

  • Use weighted grade entries with score, max score, category, and course.
  • Review overall weighted average, per-course averages, and use the what-if calculator.

Teachers

Path: More → Teachers.

  • Manage instructor profiles and link them to courses and work items.

Insights

Path: More → Insights.

Purpose: turn school data into actionable trends.

  1. Attendance: donut chart with Present, Late, Absent counts to detect instability.
  2. Assignments Completion: donut chart with Completed, Pending, Overdue to prioritize focus.
  3. Grade Distribution: bar chart (A/B/C/D/F buckets) to find performance clusters.
  4. Per-Course Grades: bar chart of weighted course averages to prioritize weak courses.
  5. Study Time Trend: line chart of study minutes by day (last 7 days) to check consistency.
  6. Study Time by Course: bar chart of minutes per course to compare effort allocation.
  7. Exams Timeline: horizontal bar chart of upcoming exams by days left for revision sequencing.
  8. Weekly Schedule Heatmap: day grid showing Lessons and Assignments Due intensity to rebalance workload.
  9. Course Load: dual bar chart showing Credits and Weekly Hours per course to detect mismatches.
  10. Performance Over Time: line chart of grade percentage by date to track trends.

Best practice: check Insights weekly, then adjust Planner, Work, and Courses accordingly.

Reminders and Notifications

Path: More → Settings → Reminders.

  • Set first and second reminder lead times (hours before due date/test).
  • Per-item reminder toggle exists on assignment/task/exam forms.
  • Marking an item Done clears reminders; switching back to To Do can re-schedule if enabled.
  • Best practice: reserve reminders for high-priority items only.

Cards

Path: Cards tab.

  • Create quick-access cards (ID, access, transit, etc.) with pinning and reorder support.

Widgets (Pro)

  • Widgets are available on Pro and support home-screen placement with per-widget configuration.
  • Widget types: Next Lesson, Today, Assignments, Exams, Course summaries.
  • Widget setup: iOS Home Screen → Add Widget → ClassPilot → choose size/configuration.

Sync, Imports, Backup (Pro)

Path: More → Settings → Ecosystem.

  • Calendar Sync: integrate with system calendar workflows.
  • Import Tools: bring external school data into ClassPilot (LMS exports, Moodle, Google Classroom, Canvas, Microsoft Teams depending on plan).
  • Import flow: choose source → preview/mapping → import → verify in Courses/Work.
  • Backup & Restore: export and restore app data for migration and recovery.

Intelligence

Path: More → Intelligence.

  • AI-assisted suggestions speed up repetitive planning choices (icons, colors, presentation style).
  • Use Intelligence for consistent visual suggestions; you can edit any suggestion before saving.
  • Best results come from clear item names (course title, assignment title) before requesting suggestions.

Settings

Path: More → Settings.

  • Configure reminders lead times, appearance/theme/accent color, ecosystem tools, and subscription settings.
  • Ecosystem tools include calendar sync, import tools, backup and restore.

Workflow Recommendations

  1. Semester setup: create courses, assign teachers, set colors, add recurring lessons.
  2. Deadline setup: add known exams early with weight and reminders.
  3. Weekly planning: add assignments/tasks, set priority, update statuses daily.
  4. Daily execution: use Work for quick actions; use Planner for time-based view.
  5. Weekly review: check Insights and Grades, then rebalance next week.

Tips

  • Use color coding consistently by subject to make filters and groups easier to scan.
  • Use reminders on high-priority items only to reduce notification fatigue.
  • Use task status actively: To Do → In Progress → Done for clearer workload visibility.
  • Keep course metadata complete (teacher, location, credits) to improve summaries and navigation context.

Free vs Pro

Free limits: Courses 1, Teachers 2, Lessons 2, Assignments 2, Exams 2, Tasks 2, Cards 2, Documents 5, Reminders 1.

Free includes: full grade visibility, themes, widget preview.

Pro (paid): unlimited items, home widgets, expanded imports, backup/restore tools, advanced dashboard customization, advanced export/sharing, priority support.
